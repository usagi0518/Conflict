# Conflict (Spec-driven Prototype)

仕様書通りの完成版に向けた段階実装プロトタイプです。

## 実装済み（継続中）
- 盤面バトル（召喚 / 自動進軍 / キングスキル）
- 5ユニット（Pawn, Knight, Bishop, Rook, Queen）
- チュートリアル + Stage1〜50 のタイトルデータ
- 6キャラのCodex（台詞・ステータス・スキル）
- 年表と分岐エンディング一覧
- ステージチップから任意ステージを選択して試遊
- 育成プロトタイプ（EXP投入・レベルアップ・イデア解放）
- 状態異常プロトタイプ（凍結・恐怖・拘束）
- エンディング分岐の簡易判定シミュレーター
- 一部キャラ個性（背水ATK/拘束付与/回復盾）の戦闘反映

## プレイ
`index.html` をブラウザで開く。

## 次に実装するもの
1. 各ステージ固有の敵編成・イベント演出
2. キャラ固有スキル効果の本実装（凍結・恐怖・拘束・反射など）
3. 育成（イデア・ツリー / 親密度 / クラスチェンジ）
4. エンディング分岐条件の判定
