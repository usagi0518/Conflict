# Conflict (JavaScript Vertical Slice)

ストーリー重視タワーオフェンスRPG **Conflict** の縦切りプロトタイプ。

## できること
- リアルタイム戦闘（召喚・自動進軍・キング拠点攻防）
- 4ユニット（Pawn / Knight / Bishop / Rook）
- ステージ進行（T1, S10, S20, S30）
- ステージごとに異なるキングスキル
  - Meteor（範囲打撃）
  - Freeze（敵進軍停止）
  - Collapse（通行不能タイル生成）
- キャラクター設定を閲覧できる Codex UI

## 実行
`index.html` をブラウザで開くだけでプレイできます。
